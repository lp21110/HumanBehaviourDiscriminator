MoMask: Generative Masked Modelling of 3D Human Motions

What is it: framework for text-driven 3D human generation

Typical use of generative transformers for modelling human motions:
-motions are vector-quantized (they are given an identification vector)
-they are then inputted into an autoregressive model
	('autoregressive model' - predicts future/ current values using past values of the same variable)
-is generated in a unidirectional order (previous tokens determine future tokens)
	-limiting: motion is generated only by the preceding (rather than global) context
	-limiting: errors might accumulate over generation process

Towards Human-like Virtual Beings: Simulating Human Behaviour in 3D Scenes

Aim: For agents to be 'holistic goal achievers', and naturally adapt to environmental dynamics to be 'autonomous' agents. Three major barriers:
	1. Holistic goal achievement: perception to action
		○ e.g. high level goal: get ready for work. 
		Now, agent should be able to process perceived current state (i.e. lying on the bed), then compose a series of actions, then the motions for each action (i.e. get up, use toilet, eat breakfast …)
	2. Environmental Dynamics: be able to actively adjust plans based on their environment
		○ i.e. If the bathroom is occupied, do other tasks until the bathroom is free. 
	3. Vast/ Multifaceted human behaviour space : agent has numerous viable paths they can follow to achieve a goal (i.e. if the task is 'get ready for work', agent can shower then eat, or eat then shower) 
	(i.e. the agent can decide to act based on their requirements/ beliefs/ feelings 
	e.g. if agent wants to get ready as quickly as possible, eat while the bathroom is occupied
	However if the agent wants to save energy costs, can wait for shower to become free instead)
		○ Agent must be able to process priorities and values, and be able to guide its selection of actions accordingly
